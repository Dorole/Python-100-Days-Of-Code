# U.S. States Game

Type in the name of a U.S. state and its name will appear on the U.S. map. Get all 50 to win.
Type "exit" to close the game without winning.
Type "help" if you get stuck - it will generate a .csv file with the names of all unguessed states. Then restart the game.

The purpose of this exercise was to apply the knowledge about reading from and writing to a .csv file with Pandas.
The program also uses the Turtle library to display the image, text and receive user input.

To play, download the project (or the States-Game folder only) and run the <b>__US-States-Game__.exe</b> file.
