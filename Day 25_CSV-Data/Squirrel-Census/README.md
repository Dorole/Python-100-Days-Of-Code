# Squirrel Census

The program reads the .csv file containing various data collected during the 2018 census of squirrels in Central Park, NY. Read more about it [here](https://data.cityofnewyork.us/Environment/2018-Central-Park-Squirrel-Census-Squirrel-Data/vfnx-vebw/about_data).

The program extracts the values of the number of squirrels for each fur color.
Finally, it creates a new .csv file containing only the data on the number of squirrels in each color.

The purpose of this exercise was to get familiar with working with .csv files on a basic level, as well as using the Pandas library and reading the Pandas docs.
