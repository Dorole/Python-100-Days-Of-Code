# GUI with Tkinter

A simple program that allows the user to choose between conversion from miles to kilometers and kilometers to miles.
Based on the choice, the text labels change and the calculation method changes. 
The user can type in a number in the text field and then click on the Calculate button to convert the units.

This project is a wrap-up of lessons on Tkinter basics. I learned about different Tkinter widgets and geometry managers, as well as *args and **kwargs. 

To try it out, download the project and run __Unit-Converter.exe__
