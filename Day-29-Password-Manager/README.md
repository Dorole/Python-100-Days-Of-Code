# Password Manager - Tkinter

A password creator program that takes the user input for a website name, e-mail and a password and
saves it to a text document on button click.
There is an option to generate the password as well (random module).
The generated password is automatically copied into clipboard (pyperclip  module).
The logic for random password generation is re-worked from [Day 5](https://replit.com/@dorole1/password-generator).

This is a wrap-up project on Tkinter. 
I plan to add some sort of encryption so a bit more work will be done here.
