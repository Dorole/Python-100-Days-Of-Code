# Pomodoro Timer - Tkinter

A pomodoro timer with a simple interface that counts down 4 25-minute work sessions with 5-minute breaks in between and 
a 15-minute long break at the end of the cycle.
The timer starts by pressing the START button and can be reset by pressing the RESET button.
At the end of every work session a checkmark appears at the bottom of the screen. 
The count-down is displayed in the middle of the screen.

I broadened the tutorial project a bit, so I also used some simple sounds (via pygame) - on button click, at the beginning 
of every session, at the end of one pomodoro cycle and when counting down last three seconds of every session. I also implemented
a pause functionality, created a simple event system and learned how to use enums and lambda functions.
