# Pomodoro Timer - Tkinter

A pomodoro timer with a simple interface that counts down 4 25-minute work sessions with 5-minute breaks in between and a 15-minute long break at the end of the cycle.
The timer starts by pressing the START button and can be reset by pressing the RESET button.
At the end of every work session a checkmark appears at the bottom of the screen. 
The count-down is displayed in the middle of the screen.

N.B. The program is functional, but the code requires work. 
I plan to refactor to remove global variables and separate concerns of two main functions which currently do too many things.
