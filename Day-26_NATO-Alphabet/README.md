# NATO Phonetic Alphabet - List and Dictionary Comprehension

A simple program that reads the user's input and outputs <a href="https://www.isesassociation.com/do-you-know-what-nato-phonetic-alphabet-is/">NATO Phonetic Alphabet codes</a>.
In case the user inputs a symbol, a number or a letter not contained in the list of codes, the program prints out "-".

The goal of this exercise was to use list and dictionary comprehension.
Dictionary comprehension is used to store the data from the .csv file. 
List comprehension is used to handle input and output. 

The program runs in the console. To try, download the project and run __Phonetic-Alphabet.exe__
